## 📌 About This Project

This is my personal portfolio website — a fully custom-designed, multi-page website that showcases my skills, work experience, volunteer activities, and projects.

Built from scratch using pure **HTML**, **CSS**, and **JavaScript** — no frameworks, no templates. Every animation, layout, and interaction was hand-coded to reflect my style and technical ability.

---

## ✨ Features

- 🎨 **Dark futuristic UI** — animated grid background, glowing orbs, and cyan accent theme
- ⌨️ **Typing animation** — cycling hero text with rotating subtitles
- 📱 **Fully responsive** — works perfectly on mobile, tablet, and desktop
- 🍔 **Hamburger menu** — smooth mobile navigation with full-screen overlay
- 📧 **Contact form** — powered by EmailJS with mailto fallback
- 🌟 **Smooth page transitions** — fade-in/out between pages
- 🎯 **Skill bars** — animated programming skill progress bars
- 💼 **Projects showcase** — cards with live demos, GitHub links, and coming-soon badges
- 🟢 **"Available for Work" badge** — pulsing green status indicator
- ✨ **Particle canvas** — floating particles on the projects page

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| **HTML5** | Page structure & semantic markup |
| **CSS3** | Animations, responsive layout, glassmorphism effects |
| **JavaScript (Vanilla)** | Typing effect, hamburger menu, form logic, particles |
| **Font Awesome 6** | Icons throughout the site |
| **EmailJS** | Contact form email delivery |
| **GitHub Pages** | Hosting & deployment |

## 🚀 Getting Started

### View Online
👉 [https://omarshawqi7722.github.io/personalweb/](https://omarshawqi7722.github.io/omar-shawqi-portfolio/)

### Run Locally

```bash

git clone https://github.com/omarshawqi7722/personalweb.git

# Navigate to the folder

# Open index.html in your browser
```
